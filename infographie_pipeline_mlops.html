Pipeline MLOps Industriel

De l'exploration Jupyter à l'inférence en production.

1. Exploration & Prototypage

L'aventure commence dans Jupyter Notebooks. Les data scientists explorent les données, réalisent l'Analyse Exploratoire des Données (EDA) et testent les premiers algorithmes (Random Forest, XGBoost) de manière interactive.

Jupyter EDA Prototyping

2. Data Version Control (DVC)

Le code est versionné avec Git, mais les grands ensembles de données ne peuvent pas l'être. DVC agit comme un pont, versionnant les pipelines de données et les datasets volumineux sur un stockage cloud (S3) tout en restant lié à Git.

Git DVC Data Versioning

3. Experiment Tracking (MLflow)

Les scripts d'entraînement sont automatisés. MLflow enregistre chaque expérimentation : hyperparamètres, métriques de performance (RMSE, ROC-AUC) et artefacts de modèles. Le meilleur modèle est promu dans le Model Registry.

MLflow Tracking Model Registry

4. Déploiement & Serving

Le modèle promu est packagé via Docker et exposé sous forme d'API REST via FastAPI. Pour des charges de production massives, le conteneur est déployé sur un cluster Kubernetes garantissant auto-scaling et haute disponibilité.
