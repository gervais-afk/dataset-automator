# Stationnarité

**Definition**: Propriété d'une série temporelle dont les caractéristiques statistiques, telles que la moyenne et la variance, restent constantes dans le temps. Prérequis pour la modélisation classique.

**Related Tools**: statsmodels, ADF Test, KPSS Test
