# Caractéristiques Retardées (Lagged Features)

**Definition**: Variables créées en décalant les valeurs passées d'une série temporelle pour capter l'autocorrélation lors de l'entraînement de modèles d'apprentissage automatique.

**Related Tools**: Polars, Pandas, scikit-learn
