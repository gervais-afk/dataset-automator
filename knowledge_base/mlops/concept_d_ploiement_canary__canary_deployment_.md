# Déploiement Canary (Canary Deployment)

**Definition**: Stratégie de déploiement progressif où une fraction mineure du trafic réel est d'abord routée vers la nouvelle version du modèle pour détecter d'éventuels bugs.

**Related Tools**: Kubernetes, KServe, Seldon Core
